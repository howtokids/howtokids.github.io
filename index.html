my uploader

PRIVATE TOOL

my uploader is a private, single-owner tool made by the How to KIDS team. It uploads videos to, and manages videos on, the owner's own YouTube channels: How to KIDS and Optimus Robot News.

It uses the YouTube Data API v3 after the channel owner signs in with Google and grants permission. It is not offered to the public, and it never accesses anyone else's account.
